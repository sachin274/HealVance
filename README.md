# 🩺 Healvance – Healthcare Video Appointment Platform

**Healvance** is a web-based healthcare prototype developed during a 2-day hackathon. The goal was to build a platform that allows doctors and patients to schedule and conduct **real-time video appointments**, improving accessibility to medical care.

> ⚠️ This project is a **hackathon prototype** and is not fully functional. Key features were designed and partially implemented under time constraints.

---

## 🚀 Features (Prototype Scope)

- 📹 **Real-Time Video Appointments**  
  Video calling functionality powered by **Socket.IO** (partially implemented).

- 🧑‍⚕️ **Doctor-Patient Interaction Workflow**  
  Planned features for booking, availability management, and live consultation sessions.

- 🎨 **Clean, Responsive UI**  
  Built using **HTML**, **CSS**, and **vanilla JavaScript** with a focus on accessibility.

---

| Technology | Purpose                          |
